# ItemNameCopy

インベントリやチェストでアイテムへカーソルを合わせ、`Ctrl+C`で表示名をクリップボードへコピーするクライアント専用Mod
コピーできたときだけ、コピーした名前をアクションバーへ表示する

## 導入

- 利用するMinecraft版とLoaderに一致するJarを、クライアントの`mods`フォルダーへ一つだけ入れる
- Jar名は`item-name-copy-<Mod版>+<Loader>-mc<Minecraft版>.jar`
- Minecraft版は完全一致が必要で、Fabric、Forge、NeoForgeのJarはそれぞれ別に選ぶ
- サーバーへの導入は不要
- Fabric APIやArchitectury APIなどの追加Modは不要
- ビルド対象の定義は[versions](versions)にあるが、定義やビルド成功だけでは動作確認済みを意味しない
- 収集した成果物の`verification-manifest.json`にはJarのSHA-256と動作確認状態を記録する
  - `runtimeVerification: pending`の成果物はゲーム内での確認が必要

## 使い方

- インベントリ、チェスト、作業台、かまど、金床などで、空でないスロットへカーソルを合わせて`Ctrl+C`を押す
- 左右どちらのCtrlでも使え、長押しでは一度だけコピーする
- 日本語名、翻訳された名前、金床などで付けた名前をそのままコピーする
- 表示名の文字列だけをコピーし、装飾、アイテムID、個数、Loreは含めない
- 名前の前後の空白や改行はそのまま残す
- 検索欄や金床の名前入力欄にフォーカスがある場合は、通常の文字列コピーを優先する
- 空スロットではクリップボードを変更しない
- 標準のコンテナ画面を継承するMod画面も対象とし、レシピビューアー独自の疑似スロットは対象外
- キー変更やコピー形式の設定画面はない

## ソースからビルド

- Java 25でGradle Wrapperを実行する
- Minecraftごとのコンパイル用JavaはToolchainで取得するため、初回はネットワーク接続が必要
- PowerShellで全対象をビルドし、`build/libs`へ収集する

```powershell
./gradlew buildAndCollect
```

- 一つの対象をビルドする場合はNode名を指定する

```powershell
./gradlew '-Ptarget=1.21.1-fabric' :1.21.1-fabric:build
```

- [ ] 配布する各JarのSHA-256を動作確認したJarと照合している
- [ ] 配布するすべての組み合わせでクライアントが起動する
- [ ] サバイバルとクリエイティブのインベントリ、チェスト、作業台、かまど、金床でコピーできる
- [ ] 各Loaderで標準コンテナ画面を継承するMod画面を一つ確認している
- [ ] 空スロットで既存のクリップボードが維持される
- [ ] 通常名、カスタム名、日本語名、前後の空白が期待どおりにコピーされる
- [ ] 左Ctrlと右Ctrlで動作し、長押しでも成功通知は一回だけ表示される
- [ ] Ctrl以外の修飾キーとの組み合わせでは発火しない
- [ ] クリエイティブ検索、レシピブック検索、金床の入力欄で選択文字列をコピーできる
- [ ] 他Modが先に処理したキー入力を上書きしない
- [ ] コピーによってアイテム、スロット、コンテナの状態が変わらない
- [ ] シングルプレイと、サーバーにこのModを入れないマルチプレイ接続で動作する
